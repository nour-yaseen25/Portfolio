# Nour Yaseen Portfolio

A clean and responsive personal portfolio for a Computer Engineering student focused on web development and software engineering.

## Live Demo

https://nour-yaseen25.github.io/Portfolio/

## Overview

This project is a simple one-page student portfolio built to present personal profile information in a professional format.

The current portfolio includes five core sections:

- Home
- About
- Skills
- Education
- Contact

## Features

- Modern, responsive layout for desktop, tablet, and mobile
- Light and dark mode toggle
- Theme preference persistence using localStorage
- Smooth section navigation with active link behavior
- Contact links for LinkedIn and GitHub

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
- Bootstrap 5 (CDN)
- Font Awesome (CDN)
- Google Fonts (CDN)
